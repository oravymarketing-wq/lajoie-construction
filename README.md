# Lajoie Construction inc. — site web

Site statique (HTML, CSS, JS) de Lajoie Construction inc., entrepreneur général à Joliette (Lanaudière). Réalisé par ORAVY.

- 6 pages : accueil, résidentiel, commercial, réalisations, soumission, 404
- Aucune dépendance externe : polices et images hébergées dans le dépôt
- Prêt pour GitHub Pages (branche `main`, dossier racine)

## À compléter
- Formulaire : mettre l'URL de réception dans `data-endpoint` (soumission.html). Sinon il prépare un courriel vers admin@lajoieconstruction.com.
- Nom de domaine : remplacer `https://lajoieconstruction.com` dans les balises canonical, og:url et sitemap.xml si différent.
